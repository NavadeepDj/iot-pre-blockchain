1
Produce Data

Encrypt sensor data with the owner's public key and register on blockchain via IPFS.

2
Grant Access

Owner authorises a specific recipient by generating a re-encryption key (kfrag) on-chain.

3
Proxy Re-Encrypt

The proxy fetches encrypted ciphertext from IPFS and transforms it for the recipient — without ever seeing the plaintext.

The proxy worker polls the blockchain for pending grants, applies the PRE transformation using kfrags, and uploads the re-encrypted capsule back to IPFS.
4
Decrypt Data

Recipient fetches re-encrypted data from IPFS and decrypts it with their own private key. No key sharing necessary.
